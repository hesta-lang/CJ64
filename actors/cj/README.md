# CJ DynOS actor

Required runtime model name: \`cj_geo\`.

Place the converted CJ DynOS actor and its textures in this folder. The actor must be compatible with the **native SM64CoopDX player skeleton and animation layout**.

The replacement script only changes the model assigned to the existing \`marioObj\`. It does not create a new skeleton, animation controller, camera or collision body.

A standalone GTA San Andreas DFF/TXD cannot simply be renamed to \`cj_geo\`; it must be converted to the DynOS format and rigged for the SM64 player animation hierarchy.

No CJ model asset is included yet.
