# CJ source model assets

Add the files from the supplied `CJ64-CJ-Model-Source.zip` here. Keep the FBX and texture maps together because its embedded paths are relative:

- `head.png`
- `upper body.png`
- `legs.png`
- `shoes.png`

Source: **Carl Johnson (CJ), by Tsaphnat (Tsaphnat Mbuyi), Sketchfab** — https://sketchfab.com/3d-models/carl-johnson-cj-647f5417720344cb8c2079edd48704ac — **CC BY 4.0 Attribution**. Preserve attribution and the source link in derivatives.

These files are authoring sources only. They must be retargeted to the native SM64CoopDX Mario Armature and exported before the game can load `cj_geo`.
